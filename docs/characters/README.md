# Character Profiles

This directory contains the authoritative per-character references used by agents and contributors when creating portraits, sprite sheets, UI assets, gameplay mechanics, optimization work, and other character-specific content.

Use a profile only for facts that it explicitly establishes. Do not infer biography, statistics, traits, abilities, proportions, equipment preferences, or gameplay behavior from portrait art. When a profile and an asset appear to disagree, stop and resolve the conflict before producing dependent work.
